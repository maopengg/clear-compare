# clear-compare

Cross-platform file comparison, merge and folder synchronization app built with Rust, Tauri 2 and Leptos.

The application is in the planning stage. The native Rust core will handle comparison, merge and safe synchronization. Leptos will provide a Rust-authored interface compiled to WebAssembly inside the system WebView, using Trunk for frontend builds.

Development plan: [docs/development-plan.md](docs/development-plan.md).
