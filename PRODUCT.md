# Product

## Register

product

## Platform

web

The interface is a desktop WebView, packaged for macOS, Windows and Linux.

## Users

People comparing and synchronizing local project directories. The initial acceptance scenario is selective code synchronization with directory and filename exclusions.

## Product Purpose

A usable open-source desktop client for file comparison, merge and folder synchronization, with a long-term feature roadmap informed by Beyond Compare.

## Positioning

Inspect differences and review a concrete synchronization plan before changing files.

## Brand Personality

Simple, modern desktop interface. Chinese by default, with an English switch.

## Design Principles

- Make source, destination and operation direction explicit.
- Keep content equality and incomplete verification visibly distinct.
- Show what will change before executing a synchronization plan.
- Put comparison results and readable text differences at the center of the workspace.

## Accessibility and Inclusion

Use semantic controls, visible focus states and textual state labels. Implement keyboard and reduced-motion support; do not claim a formal accessibility conformance level before testing.
