# 克隆和初始化仓库

首页“克隆 / 初始化”打开紧凑的内联创建区，与已有仓库收录区互斥显示。选择已有父目录并输入一个新的目录名，先检查计划再确认执行；目标目录必须不存在，包括空目录和符号链接。检查展示规范目标、操作和选项，不会提前创建目标或连接远程。

初始化支持指定初始分支和普通/裸仓库。克隆支持 HTTPS、HTTP、SSH、Git URL、SCP 风格 SSH 地址，或有效本地仓库的绝对路径；可指定分支或标签、普通/裸仓库、浅克隆深度。完整克隆的深度留空；指定深度为 1–1000000。克隆不会递归初始化子模块，创建后可进入已有子模块管理。内嵌 HTTP 用户信息、密码、查询参数或片段的地址被拒绝；使用本机 Git/SSH/凭据配置完成认证，不在应用里保存密码。

## 执行与保留

计划只包含原生捕获的目标位置与类型化 Git 参数，UI 确认只传一次性计划 ID。再次执行前及发布前复查父目录身份、目标不存在和本地来源仓库身份；禁止在 Git 管理目录中创建。改变输入撤销检查区，失效计划必须重新检查。

执行时先在父目录中创建一个独立、私有的 `.clear-compare-create-*` 目录。初始化/克隆只对这个目录运行；本地克隆使用 Git 传输而非本地对象硬链接，可用浅克隆，并在来源被删除后独立使用。Git 返回成功后验证新仓库，再通过系统原子的“不覆盖已有目标”重命名发布，最后调用已有持久化收录流程。不会覆盖、清空或自动删除已有目录。

发布前的失败/取消保留临时目录和终态日志，并展示路径。发布成功后如果工作台设置无法保存，状态明确为“仓库已创建，收录未完成”，保留最终仓库，提供预填路径的补收录入口。成功后自动出现在首页，可直接进入 Git 工作台。操作结果显示耗时和可展开的原始 Git 输出；完成后折叠参数，优先展示结果，可“再次创建”。关闭/Esc 返回入口焦点，执行中关闭被禁用，底部提供取消。

使用统一 Git 子进程执行器，运行中取消会停止进程树，清理失败优先作为失败报告，不把尚未停止的进程称作取消完成。克隆有 30 分钟执行上限，其余网络操作仍为 120 秒；初始化等本地命令为 30 秒。统一输出预算为标准输出 16 MiB、诊断 256 KiB。当前使用不带进度洪流的 Git 调用；提供执行中/取消和终态耗时，不声称实时接收对象数量或百分比。

应用数据目录的 `git-creation/<id>/` 保存只创建一次的 intent、临时目录路径/身份以及 result JSON。失败保留的目录不自动清理；跨重启自动续传、自动恢复收录和图形化历史清理浏览器仍待实现。若进程在发布后、结果记录前退出，可依据 intent 中的最终路径及 staging 记录人工检查；当前不声称完全自动的崩溃恢复。

## 验证边界

九个原生临时仓库测试覆盖普通/裸初始化，完整/浅克隆、分支/标签、来源删除后对象独立，非法参数/目标已有/元数据目录拒绝、父目录/来源 Git 身份替换、执行前取消/过期计划、失败临时目录、收录保存失败及补收录。运行中取消通过独立本机 HTTP 监听器阻塞实际 Git 克隆后触发，验证取消结束、保留临时目录和终态日志，不访问外部仓库。

`scripts/check-repository-creation.cjs` 使用真实 WASM 与模拟 IPC，覆盖类型化选项、先检查后执行、原生 ID、输入失效、目录选择入口、取消/焦点、失败保留、运行中取消反馈、补收录入口、自动收录、日志转义、双语和 900/1440 布局。此脚本不证明真实系统选择器、网络凭据或三平台原生窗口行为。外部 HTTPS/SSH 认证与长时间大型克隆仍需真实环境验收；成功构建不替代它们。
