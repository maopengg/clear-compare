# 仓库显示分组与排序

首页默认显示 Git 仓库分组。自动分组优先使用原生层提取并规范化的远程匹配标识（origin 优先，兼容 SSH/HTTPS）；没有远程时仅将共享同一个 Git 管理目录的本地仓库和关联工作区归在一起。不会仅凭目录同名合并无关仓库。所有副本、裸仓库、关联工作区仍是独立条目，打开各自的 Git 状态和文件规则。

“分组 / 排序”打开工具栏下的紧凑设置区，与克隆和收录管理互斥。可以创建、重命名、删除自定义分组；选择多个仓库后，设置到自定义分组、各自单独显示，或恢复自动归组。名称最多 80 个可显示字符（320 UTF-8 字节），去除外层空白，不允许重复名称（忽略大小写）。原生分组 ID 与名称分离，重命名不影响成员。删除分组会让其成员恢复自动归组，不删除仓库或改变远程地址。

选择区支持名称/路径/分组名筛选、100 项分页、跨页选择、选择本页、选择全部匹配和清空选择。“全部恢复自动归组”还会清除已移除记录的保留覆盖，但保留自定义分组定义。原生层拒绝未知仓库/分组、重复或空的选择，单次最多 4096 个仓库。自定义分组最多 128 个，包含暂时移除记录的覆盖最多 8192 项。

显示设置包括名称、路径、最近打开时间、变更数量排序，升/降序、收藏优先和分组/平面视图。修改后明确显示尚未保存，点击保存才应用；失败保留草稿，首页继续按已保存设置显示。“最近”分类始终按最新打开优先，不让收藏覆盖时间顺序。分组视图按组名、最小成员路径、最新成员打开时间或成员变更总数排序，组内使用相同排序；收藏优先时含收藏的组优先，组内收藏优先。相同值按路径/原生 ID 稳定排列。

首页搜索也匹配自定义分组名称。分组设置不改变项目文件排除、搜索配置或 Git 地址，不共享不同副本的文件规则，也不会自动复制文件。保存只写工作台目录配置，原生原子保存成功后才更新内存；取消和保存失败不产生部分归属更新。

设置支持旧版目录默认迁移，重启、重扫、创建仓库和移除/重新收录后保留。重新定位路径时，原记录的显式分组覆盖转移到新记录；合并已发现的新位置时原记录显式选择优先，否则保留新位置现有选择。删除分组会一并清理已移除记录的成员关系，防止后续重新添加时复活已删除分组。

原生临时仓库测试覆盖分组 CRUD、原生多选、自动/单独覆盖、排序设置、Git 配置与文件规则隔离、重启/重扫、重新定位、移除/重新收录、失败回滚、取消、旧目录迁移和非法持久化数据。真实 WASM/模拟 IPC 界面测试验证自动远程及无远程工作区分组、自定义分组与安全文本、归属刷新、搜索/排序、失败保留、257 项选择及双语紧凑布局。模拟 IPC 不代表原生窗口验收。

当前分组只组织 Git 仓库；比较项目继续使用已有项目库。折叠分组、手动拖动排序、比较项目与 Git 仓库混合分组、跨仓库配对比较入口以及完整界面状态恢复仍待完善。所有操作保留本地副本，不把显示分组合并说成 Git 仓库合并。
