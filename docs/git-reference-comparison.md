# 工作台中的分支与工作区比较

分支菜单提供“与当前提交比较”和“与工作区比较”。结果显示在当前仓库工作台内，保留工作区变更列表、历史页和文件编辑器。返回仓库不执行检出或写入，切换仓库时清除旧比较上下文。

比较页可以更改左侧分支或标签，右侧可以选择另一个分支/标签、当前提交、暂存区或工作区。裸仓库仅支持提交来源。工作区默认不包含未跟踪文件，可显式纳入 Git 未忽略的未跟踪文件。应用当前仓库的文件排除规则。

## 捕获与复查

- 界面传递原生捕获的仓库 ID、状态版本和引用 ID，不传仓库路径或拼接修订表达式。
- 发起或重新比较时先读取最新仓库状态，再由原生复查仓库映射、目录身份、状态版本和引用选择；分支与标签解析为完整提交对象，暂存区固定到捕获的索引对象。
- 比较只读取本地 Git 对象，不检出、暂存、提交、更新引用或触发对象下载。
- 工作区按磁盘原始字节捕获，不含编辑器未保存的缓冲区，不应用 clean/smudge 或换行转换。打开文本差异时检查捕获内容是否仍有效，变化后要求重新比较。
- 内容相同使用对象身份判断，不依赖时间相同。权限变化保持为差异；链接、子模块、缺失项与读取错误仍按原 Git 比较语义区分。
- 对比失败保留上次成功结果；“已捕获的比较来源与限制”显示实际结果来源，不能把失败的新来源选择当作已完成结果。

## 浏览

文件列表支持搜索整个比较、仅差异和每页 500 项。文本左右对齐，逐行及字符差异着色；左右独立水平滚动，同步垂直滚动，每页最多渲染 500 个对齐行。加载状态在底部，失败保留已打开的文本。二进制或过大文本按现有 Git 预览限制报错，完整图片/二进制与编辑器桥接尚未接入这个入口。

## 验证范围

`workbench_comparison` 验证捕获引用、任意目标引用、分支移动后的固定对象、工作区变化复查、暂存区固定对象、附注标签、忽略与项目排除规则、未跟踪开关、取消、非法 ID、过期状态及裸仓库限制。原 Git 来源测试继续验证其底层语义。

浏览器验证使用模拟 IPC；真实桌面 Git 集成、三系统安装与完整编辑/合并互通仍需要后续验收，不能据此把完整工作台目标标为完成。
