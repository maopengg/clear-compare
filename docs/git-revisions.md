# 浏览提交文件与本地比较

历史页选择提交后，可点击“浏览此提交文件”；提交右键菜单也提供“浏览此提交的仓库”。该页面展示所选提交的全部跟踪条目，包括该次提交未修改的文件，不受工作树项目排除规则影响。不会切换分支、检出文件、暂存、修改索引或下载缺失对象。

## 目录与对象身份

首次打开只读取提交的根目录。后续展开目录按需执行 `ls-tree`，使用原生捕获的目录 ID 和树对象，不把界面路径拼回 Git 命令。目录内支持名称筛选、每页 300 项、根目录和上一级导航。父目录 ID 与提交、仓库绑定。返回提交历史保留历史查询/选择/滚动位置；回到文件编辑器后，历史浏览状态在本次进程内保留。

提交必须来自历史中的完整 40/64 位对象身份，解析为固定提交/树。引用移动或本地检出改变后，仍显示原来提交的文件。后续读取复查仓库根、Git 管理目录及当前映射；仓库被替换则拒绝继续。同一仓库/提交复用树，最多保留四个历史浏览会话；回收未被当前文件历史保护的旧会话，失效会话须重新打开。文件历史返回时释放保护，避免连续查看版本破坏原始阅读器。

Git 参数固定禁止 replace objects、lazy fetch、文本转换和外部 diff。文件名通过 NUL 记录解析，原生路径和界面展示名称分开，UI 只回传 ID。Unix 非 Unicode 名称保留原生路径，界面可能使用替代字符；平台无法表示的名称明确报错。链接只查看目标字节，子模块只展示 Gitlink 提交信息，不跟随、不展开、不初始化。

目录每次 Git 输出限 16 MiB；每个会话最多捕获 50000 条目、估算 64 MiB 名称数据、128 层及 16384 个原生路径编码单元。超限拒绝该次读取，不把截断树显示为完整结果。取消和失败保留原来的目录/文件。

## 正文与十六进制

普通文件或链接首次读取时，原生 Git 输出写入私有临时文件，按 Git `blob <size>\0` 格式重新计算 SHA-1/SHA-256，并复查声明字节数。后续分页读取这个已校验对象；临时文件不会作为编辑目标或释放给 UI。每个会话最多缓存两个文件，全工作台缓存上限 512 MiB，缓存淘汰只影响再次读取速度，不改变固定对象身份。单对象上限为 256 MiB。

- 最多 4 MiB 的 UTF-8/带 BOM 的 UTF-16 正文按 500 行分页，显示原始编码和 LF/CRLF/CR/混合换行信息。超长行仅预览前 8192 字符，并明确提示；不会修改对象字节。
- 二进制、不支持编码或较大的文件自动进入十六进制，每页 4096 字节，显示偏移、十六进制和 ASCII。大文件以磁盘缓存分页，不将整个对象放入 IPC 或 WebView 内存。可在原文与十六进制之间切换。
- 对象读取受 Git 30 秒/输出预算及运行中取消约束，沿用统一子进程组/Windows Job 生命周期管理。取消在底部显示；已有正文保留。

历史文件保持只读。返回编辑本地文件会打开同一份工作区源标签，不把历史正文直接写入本地。

## 与本地文件比较

在普通文本文件中点击“与本地文件比较”，只读取这个文件对应的磁盘路径，不列出或比较整个仓库。历史侧使用已捕获对象，本地侧限制为普通文件，采用受限读取并在生成差异后核对内容摘要和文件身份。不会用修改时间推断相同，也不执行 clean/smudge/EOL 过滤。

页面使用对齐双栏、同步纵向滚动和每页 500 行差异。缺失本地文件明确标记为不存在，历史内容与空侧比较；本地对应项为目录/链接/其他类型时拒绝文本比较。裸仓库可浏览历史，但没有本地工作文件入口。文本比较沿用每侧 4 MiB 编码字节/8 MiB 解码正文、30000 行和有界差异计算限制。

比较读取磁盘内容，不包含未保存草稿。比较完成后“编辑本地文件”使用原生捕获的文件 ID；已打开的同一文件保留原标签和未保存状态。比较失败保留原文或上一份比较结果，不生成虚假的空文件/相同状态。

## 验证和剩余边界

十项临时仓库测试覆盖：未修改文件/固定提交、按需目录与稳定 ID、父级/筛选分页、UTF-16/CRLF/空文件、超长行与字节分页、真实 17 MiB 对象、本地差异/缺失/未保存标签、裸仓库、链接/Gitlink/字面名称、错误 ID/取消/仓库替换、replace/textconv 不生效和 SHA-256 仓库。

`scripts/check-git-revision.cjs` 使用真实 WASM 与模拟 IPC 检查历史入口、目录/文件参数、正文转义、分页与失败保留、本地双栏/缺失提示/编辑跳转、链接/子模块/二进制禁用项、底部加载与取消、双语和 900/1440 布局。实际对象和磁盘读取以 Rust 测试单独验证，模拟 IPC 不证明系统窗口或跨系统安装行为。

历史版本的图片可用十六进制查看，尚未接入原有图片/表格专用预览。超过正文限制的文件目前只能按字节查看，尚无大文本的分段解码、语法高亮、历史对象导出/恢复为工作文件或工作树新增文件的反向历史查找。历史浏览会话不跨重启保留；文件历史和已提交 UTF-8 行追溯已接入，详见 [文件历史与追溯](git-file-history.md)；其他编码的追溯、补丁导出/应用等仍属于完整清单的待完成部分。
