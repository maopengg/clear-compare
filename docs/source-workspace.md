# 文件工作台

首页点击“文件 / 全局搜索”进入工作台。当前根目录来自已收录的 Git 工作树；普通目录和比较项目尚不能独立作为编辑根目录，裸仓库没有工作树，因此不出现在文件根目录选择器中。

## 浏览与编辑

目录树按需展开，文件和目录均使用原生捕获的 ID。`.git` 元数据受保护，符号链接不跟随；隐藏文件、Git 忽略规则和自定义排除规则可按仓库设置并持久化。新建文件或目录针对选定目录执行，不覆盖已有名称。单目录最多读取 50000 项，每页展示 300 项。

文本由本地打包的 CodeMirror 编辑，无运行时 CDN。多标签保留光标、滚动位置和撤销历史；切换项目、返回首页或比较视图不会销毁打开的缓冲区。支持常见 JavaScript/TypeScript、Python、Rust、HTML、CSS、JSON、Markdown、SQL、XML、YAML 高亮；其他文本使用普通文本编辑。

工具栏提供撤销/重做、当前文件查找替换、跳转行和保存。macOS 使用 ⌘S，Windows/Linux 使用 Ctrl+S，保存当前标签；工作台内 ⌘/Ctrl+Shift+F 定位全文搜索，⌘/Ctrl+P 进入文件名搜索。快捷键尚未覆盖原有比较界面的全局入口。

同时打开最多 32 个文本，单文件编码数据最多 4 MiB。支持 UTF-8 和带 BOM 的 UTF-16，底部显示原编码、BOM 和换行格式，可选择保存格式。保存前验证文件身份与原始内容，并生成校验备份；外部文件变化会阻止覆盖并保留缓冲区。窗口重新获得焦点或手动刷新时检查外部变化，当前不运行文件系统监听服务。

关闭有修改的标签时提供保存关闭、放弃关闭、取消；原生退出也检查未保存源文件。有未保存源文件时，可能改写同仓库工作树或索引的 Git 操作会被阻止。编辑标签及未保存正文当前仅在本次进程中保留，不承诺崩溃后恢复。

## 搜索

可搜索当前文件、当前目录、当前仓库或全部收录的工作树，提供文件名、完整路径、正文三种模式，以及大小写、整词、正则、多行和包含/排除规则。项目排除规则总是应用，是否遵循 `.gitignore` 可选。正文按统一换行匹配，结果携带文件内容摘要，打开时检查结果是否过期，并定位对应文字。

搜索最多接受 4096 个仓库、遍历 250000 项、返回 5000 个结果，每文件最多 200 个命中；任务有 60 秒遍历预算，单条 Git 命令另有超时和输出上限。超过限制显示截断，取消返回已收集结果。大于 4 MiB、二进制和无法读取的文件计入跳过数量；失效仓库显示警告。界面每页展示 200 条结果。当前结果为平面列表，按项目/文件折叠分组和跨文件替换尚待实现。
