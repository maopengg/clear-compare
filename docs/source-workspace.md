# 文件工作台

首页点击“文件 / 全局搜索”进入工作台。当前根目录来自已收录的 Git 工作树；普通目录和比较项目尚不能独立作为编辑根目录，裸仓库没有工作树，因此不出现在文件根目录选择器中。

## 浏览与编辑

目录树按需展开，文件和目录均使用原生捕获的 ID。`.git` 元数据受保护，符号链接不跟随；隐藏文件、Git 忽略规则和自定义排除规则可按仓库设置并持久化。新建文件或目录针对选定目录执行，不覆盖已有名称。单目录最多读取 50000 项，每页展示 300 项。

文件树右键菜单提供打开文件、复制文件名/相对路径/完整路径、在系统文件管理器中显示、排除此项，以及重命名、复制到、移动到和移到废纸篓。菜单可用 Shift+F10 或菜单键打开，方向键/Home/End 导航，Esc 返回原条目。排除使用原生路径生成转义规则，写入当前仓库设置，不删除磁盘文件。

文件操作先预览来源、目标、文件/目录数量和字节数，再执行一次性计划；复制/移动的目标通过仓库和原生目录选择器确定。目标目录按需进入、支持分页，已有同名项拒绝覆盖。源目录内部不得含 `.git` 元数据、链接或特殊文件，最多 50000 项、128 层；这些限制会明确报错。复制以磁盘内容为准，未保存的编辑不包含在内。移动、重命名和删除前须关闭该项内打开的标签，避免让编辑器继续指向旧路径。

执行前复查整个选中范围的身份、权限和内容摘要，生成并校验备份，随后保留意图、备份验证、开始执行和结果日志。复制在目标卷先暂存再原子发布；移动/重命名采用不覆盖的原子改名，当前不跨卷，不支持仅大小写变化。失败保留来源或已发生操作的现场和日志，不自动重试。备份位于应用数据目录的 `file-operations`，GUI 中尚无该类备份的恢复入口。

删除交给系统废纸篓后端，应用不提供永久删除回退；macOS 使用 NSFileManager，Windows 使用系统回收站接口，Linux 使用 FreeDesktop Trash。系统废纸篓不可用时保留原文件并报错。macOS 的“放回原处”可用性取决于系统，备份和日志仍保留。系统中显示在 macOS/Windows 定位条目，Linux 打开所属目录。这些 OS 集成尚未在三个系统上逐一运行验收。

文本由本地打包的 CodeMirror 编辑，无运行时 CDN。多标签保留光标、滚动位置和撤销历史；切换项目、返回首页或比较视图不会销毁打开的缓冲区。支持常见 JavaScript/TypeScript、Python、Rust、HTML、CSS、JSON、Markdown、SQL、XML、YAML 高亮；其他文本使用普通文本编辑。

工具栏提供撤销/重做、当前文件查找替换、跳转行和保存。macOS 使用 ⌘S，Windows/Linux 使用 Ctrl+S，保存当前标签；工作台内 ⌘/Ctrl+Shift+F 定位全文搜索，⌘/Ctrl+P 进入文件名搜索。快捷键尚未覆盖原有比较界面的全局入口。

同时打开最多 32 个文本，单文件编码数据最多 4 MiB。支持 UTF-8 和带 BOM 的 UTF-16，底部显示原编码、BOM 和换行格式，可选择保存格式。保存前验证文件身份与原始内容，并生成校验备份；外部文件变化会阻止覆盖并保留缓冲区。窗口重新获得焦点或手动刷新时检查外部变化，当前不运行文件系统监听服务。

关闭有修改的标签时提供保存关闭、放弃关闭、取消；原生退出也检查未保存源文件。有未保存源文件时，可能改写同仓库工作树或索引的 Git 操作会被阻止。编辑标签及未保存正文当前仅在本次进程中保留，不承诺崩溃后恢复。

## 搜索

可搜索当前文件、当前目录、当前仓库或全部收录的工作树，提供文件名、完整路径、正文三种模式，以及大小写、整词、正则、多行和包含/排除规则。项目排除规则总是应用，是否遵循 `.gitignore` 可选。正文按统一换行匹配，结果携带文件内容摘要，打开时检查结果是否过期，并定位对应文字。

搜索选项中的“保存当前项目搜索设置”保留查询文字、模式及过滤条件；切换回该项目或重启后恢复。目录/文件 ID 和搜索范围不写入配置，避免重启后沿用过期选择。保存失败保留原配置及当前输入。快速打开切换到文件名搜索和当前项目范围，并选中原查询文字；已有文件树不因此重新加载。

搜索最多接受 4096 个仓库、遍历 250000 项、返回 5000 个结果，每文件最多 200 个命中；任务有 60 秒遍历预算，单条 Git 命令另有超时和输出上限。超过限制显示截断，取消返回已收集结果。大于 4 MiB、二进制和无法读取的文件计入跳过数量；失效仓库显示警告。界面每页展示 200 条结果，按项目和文件折叠分组；分组计数明确对应当前页，同一文件命中跨页时重复显示分组标题。跨文件替换使用独立的完整命中文件计划，详见 [批量替换](source-replacement.md)。
