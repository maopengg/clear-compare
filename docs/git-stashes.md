# 贮藏管理

工作区工具栏的“贮藏管理”打开当前仓库的 Stash 列表；普通仓库、worktree 共用 Git 原生贮藏记录，裸仓库可只读查看已有记录。列表每页 100 项，提供说明/作者/对象筛选（当前页），最多浏览到第 10000 条偏移。

## 查看与比较

选中一条记录后可查看四类变化：

- 全部已跟踪修改：保存基线与 Stash 工作树对象比较。
- 已暂存修改：保存基线与索引对象比较。
- 未暂存修改：索引对象与 Stash 工作树对象比较。
- 未跟踪文件：Stash 第三个父对象中的根文件树；未保存未跟踪文件的记录不能选择此区域。

文件列表每页 200 项，可筛选完整记录中的文件路径；补丁每页 500 行，使用已有历史补丁预览，二进制与超长行保持限制提示。打开记录及补丁不会检出或改写工作区。列表/区域/补丁读取失败保留已成功加载的视图，记录过期需要刷新，失败不会自动循环重试。

## 保存与恢复

“保存当前修改”填写说明，可选择包含未跟踪文件。保存成功才清空说明；保存失败保留输入。未跟踪文件遵循 Git 忽略规则，勾选后由 Git 保存并从工作区清理。Git 的 Stash 命令会构造内部路径表达式，不能套用全局 `--literal-pathspecs`；原生执行器只对此已验证类型的命令豁免该选项，其他文件操作继续使用字面路径。特殊文件名有独立回归验证。

应用保留记录；弹出在应用成功后移除记录，冲突时保留记录。两者可以选择恢复索引状态。删除移除对应贮藏记录。从贮藏创建分支使用保存时的基线、恢复原索引和修改，成功后移除原记录；若恢复失败，Git 可能已经切换到新分支，界面保留该实际现场及输入，不自动切回或重试。

这些恢复/删除操作使用原生捕获的记录 ID，进入共同确认区，准备与执行前检查仓库状态及记录身份，执行前保留 Stash 对象的恢复引用。恢复引用可保留索引及未跟踪父对象，不是完整磁盘工作区备份，也不等于把原来的贮藏序号重新插回列表。未保存编辑会阻止修改工作树/索引的操作；删除贮藏不修改编辑器缓冲区。裸仓库不提供写操作。

## 验证与限制

`workbench_stashes` 通过临时仓库验证四类树和补丁、索引恢复、成功弹出、冲突保留、准备/执行间状态变化、过期顺序、同对象重复记录分页、未保存保护、分支冲突与部分失败、字面特殊文件名、仓库隔离以及裸仓库只读查看。

记录 ID 属于进程内捕获的有界缓存，重扫或缓存淘汰后需刷新。与当前工作区的额外三方比较、完整冲突解决和恢复引用的图形化管理仍属于后续工作。桌面运行与三系统安装验收不能由临时仓库测试或模拟 IPC 的浏览器测试替代。
