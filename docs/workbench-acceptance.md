# 工作台功能开发与验收

完整目标保持不变；复选框仅在代码、行为测试和对应界面证据均通过后勾选。核心层通过或界面出现按钮，不代表该项已完成。现有功能也需要在新工作台中重新核对。

## 用户确认的完整范围

建议把产品定位扩展为：**多项目工作台 + 可视化 Git 客户端 + 文件比较/合并 + 基础代码编辑器**。原有比较项目继续保留，首页同时展示扫描到的 Git 仓库。

下面是待实现和验收的功能清单，**包含你两张截图中的操作**，不代表目前都已完成。

### 1. 首页与多项目管理

- [ ] 首页展示比较项目、Git 仓库、最近打开、收藏项目。
- [ ] 添加一个或多个扫描目录，递归发现 Git 仓库；支持手动添加、重新扫描、移除收录。
- [ ] 识别普通仓库、嵌套仓库、子模块、worktree、裸仓库。
- [ ] **优先按远程地址匹配同一项目**，兼容 SSH/HTTPS；保留多个本地副本，匹配有歧义时可手动调整。
- [ ] 仓库列表展示路径、当前分支、修改数量、冲突数量、领先/落后提交数。
- [ ] 每个项目独立保存排除规则、搜索设置、比较配置、收藏分支和界面状态。
- [ ] 支持项目搜索、分组、排序、收藏，以及失效路径重新定位。

### 2. 仓库工作台与分支菜单

- [ ] 当前分支入口，搜索分支和操作。
- [ ] 分组展示：最近使用、收藏、本地分支、远程分支、标签。
- [ ] 更新项目、提交、提交并推送、推送。
- [ ] 新建分支，从指定分支或提交创建分支。
- [ ] 切换本地分支、检出远程分支并建立跟踪关系。
- [ ] 检出标签或指定提交，明确显示 detached HEAD 状态。
- [ ] 切换并更新、切换并变基到原分支。
- [ ] 将选中分支合并到当前分支，将当前分支变基到选中分支。
- [ ] 分支间比较，与当前工作区比较。
- [ ] 分支重命名、删除、设置/取消上游跟踪。
- [ ] 从选中分支创建 worktree。

### 3. 变更、暂存与提交

- [ ] 分开展示未暂存、已暂存、未跟踪、冲突文件。
- [ ] 文件树与平面列表切换，支持搜索、筛选和多选。
- [ ] 查看工作区、暂存区、HEAD 之间的差异。
- [ ] 整文件、差异块、选中行的暂存与取消暂存。
- [ ] 提交信息编辑、历史消息复用、修改最后一次提交。
- [ ] 提交前展示提交文件和统计，提交后刷新状态。
- [ ] 放弃工作区修改、恢复指定版本；操作前明确影响范围。
- [ ] 支持 `.gitignore` 编辑和右键添加忽略规则。
- [ ] 展示 Git hooks 的执行结果与错误。

### 4. 提交历史与截图中的提交菜单

- [ ] 图形化提交关系，展示分支、标签、作者、时间和提交信息。
- [ ] 按分支、标签、作者、日期、路径、文本、提交哈希筛选。
- [ ] 查看提交详情、变更文件树、逐文件差异。
- [ ] 复制提交哈希、创建/导出补丁、应用补丁。
- [ ] Cherry-pick、Revert Commit、检出指定提交。
- [ ] 浏览指定提交时的仓库文件，与本地工作区比较。
- [ ] 重置当前分支到指定提交：Soft / Mixed / Hard。
- [ ] 撤销最近提交，保留代码修改。
- [ ] 编辑历史提交信息、Fixup、Squash Into、Drop Commit。
- [ ] 从指定提交开始交互式 Rebase：排序、合并、修改信息、暂停编辑、丢弃。
- [ ] 推送到指定提交。
- [ ] 从提交创建分支、创建标签。
- [ ] 跳转父提交、子提交。
- [ ] 在浏览器打开对应远程提交页面。
- [ ] 查看文件历史和逐行追溯（Blame）。

### 5. 拉取、推送与远程管理

- [ ] Fetch、Fetch All、清理失效远程跟踪引用。
- [ ] Pull：快进、合并、Rebase 模式。
- [ ] Push、首次设置上游、推送分支和标签。
- [ ] 强制推送使用 `force-with-lease`，明确显示目标和影响。
- [ ] 添加、编辑、删除远程地址，区分 fetch/push 地址。
- [ ] 查看远程连接、认证、网络和命令错误。
- [ ] 使用本机已有 Git/SSH/凭据管理配置。
- [ ] 克隆仓库、初始化本地仓库。

### 6. 合并、变基与冲突处理

- [ ] Merge、Rebase、Cherry-pick、Revert 的进行中状态。
- [ ] 冲突文件集中列表，展示处理进度。
- [ ] 三方比较：共同基础、当前版本、传入版本。
- [ ] 支持逐块选择、接受某一侧、手动编辑合并结果。
- [ ] 保存后标记已解决并暂存。
- [ ] 继续、跳过适用步骤、中止当前操作。
- [ ] 未解决冲突、外部文件变化、操作失败时保留现场。
- [ ] 历史重写前展示操作序列，并保留可恢复引用。

### 7. Stash、标签、worktree 与子模块

- [ ] **Stash**：创建、查看、比较、应用、弹出、删除，从 stash 创建分支；可选择是否包含未跟踪文件。
- [ ] **标签**：轻量/附注标签、查看、创建、删除、检出、推送。
- [ ] **Worktree**：列表、创建、打开、定位、移除、清理失效记录。
- [ ] **子模块**：查看状态、初始化、更新、递归更新、进入对应仓库。

### 8. 全局搜索与替换

- [ ] 搜索范围：当前文件、当前项目、选定目录、全部收录项目。
- [ ] 文件名、完整路径、文件内容搜索。
- [ ] 大小写、全词、正则、多行匹配。
- [ ] 包含/排除规则，支持遵循 `.gitignore` 和项目排除项。
- [ ] 结果按项目和文件分组，展示命中行、上下文、行号。
- [ ] 点击结果直接打开文件并定位。
- [ ] 当前文件替换、批量替换；批量操作先预览。
- [ ] 搜索可取消，明确显示进度、错误和结果截断情况。
- [ ] 文件搜索与 Git 历史搜索提供独立入口。

### 9. 文件浏览、查看与编辑

- [ ] 项目文件树：展开/折叠、过滤、刷新、定位当前文件。
- [ ] 新建文件、新建文件夹。
- [ ] 重命名、复制、移动、复制文件名/路径、系统中显示。
- [ ] 删除优先进入系统废纸篓。
- [ ] 多标签打开文件，保留滚动位置和未保存标记。
- [ ] 文本编辑：语法高亮、行号、缩进、撤销/重做、查找替换、跳转行。
- [ ] 编码、BOM、LF/CRLF 状态查看与转换。
- [ ] 外部修改检测，避免直接覆盖其他程序的改动。
- [ ] 大文件分段查看，图片预览、二进制查看；保留现有表格比较能力。
- [ ] 文件编辑、Git 差异、历史版本与原有双向合并之间可直接切换。

### 10. 操作体验与跨平台要求

- [ ] 中文默认，英文可切换，菜单和错误说明完整本地化。
- [ ] macOS 使用 ⌘ 系列快捷键，Windows/Linux 使用 Ctrl 系列。
- [ ] 保存、全局搜索、快速打开文件、提交、推送等提供快捷键入口。
- [ ] 右键菜单随文件、分支、提交、仓库变化，只展示可执行操作。
- [ ] 主区域优先展示文件和差异，工具栏紧凑，辅助面板可折叠。
- [ ] 长任务后台执行，提供进度、取消、耗时和操作日志。
- [ ] 单文件操作避免遍历或持久化整个仓库清单。
- [ ] 不支持的操作不放空按钮；失败后保留输入和未保存内容。

**验收时会逐项核对截图菜单、实际执行结果、失败恢复和快捷键，而不只是检查界面上有没有按钮。**
