### Git 工作区差异与部分暂存

工作区已接未暂存/已暂存/未跟踪/冲突分组、路径筛选、平面/目录树、多选、每页 200 项，以及未暂存/已暂存/HEAD 对工作区差异。普通文本可逐块或选择删除/新增行暂存、取消暂存；跨页行选择保留。批量取消暂存只操作所选中的已暂存条目。原生捕获行/块标识，客户端不传补丁；执行前重新检查文件差异内容，使用 Git 缓存区补丁写入，磁盘工作文件保留。部分文本操作不顺带暂存权限变化。恢复引用保留旧索引文件对象或适用的 HEAD，不等于全工作区备份。

Git 变更通过原生条目转换进入文件编辑器，Git 面板保持挂载，编辑器往返保留差异与选择。加载/操作失败保留原视图与选择，不循环重试；外部状态变化要求更新快照。执行阶段补查未保存源缓冲区，避免只在计划准备时检查。
