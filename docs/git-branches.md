# 分支与版本菜单

仓库工作区工具栏的当前分支按钮打开引用菜单。支持搜索名称和快捷操作，按最近使用、收藏、本地、远程、标签分组。每组最多显示 200 项，可搜索定位；收藏持久化到当前仓库，最近记录最多 32 个本地分支。重命名后迁移相关记录，已删除引用在刷新时移除。

## 当前已接入

- 新建分支，指定起始版本，可选择创建后切换。裸仓库不能切换。
- 切换已有本地分支；远程引用使用明确的本地名称检出并跟踪，不猜测、不覆盖同名分支。
- 检出标签或指定提交，显示分离 HEAD。
- 切换并更新：检出后按已审阅的上游执行快进、合并或变基。上游缺失、多值或失效时拒绝准备。
- 切换并变基：将选中分支检出，再变基到操作前捕获的当前提交。保留选中分支原提交的恢复引用。
- 合并到当前分支、当前分支变基到选中版本。
- 分支重命名、删除、设置或取消上游。
- 选择远程和目标分支推送、首次建立上游。强制推送用针对捕获远程跟踪对象的精确租约；没有该跟踪引用时只允许目标不存在。租约拒绝后不自动重试。
- 轻量或附注标签创建、标签检出、推送和删除。
- macOS ⌘K / Windows、Linux Ctrl+K 打开提交输入；加 Shift 打开当前分支推送表单。

表单失败保留输入；历史修改类操作进入共同确认区，取消后返回原表单。Escape 先退出表单，再关闭菜单并还原分支按钮焦点。菜单支持 Tab、上下箭头导航。

## 执行与失败语义

原生层生成并复查一次性操作计划。复合检出操作在第一步之后检查当前分支与提交，Git hook 改变目标时停止后续动作。第二步失败时保留检出后的分支、冲突与 Git 状态，界面刷新实际状态，不自动切回原分支。恢复引用保护捕获的 Git 对象，不代表完整磁盘文件备份。网络命令使用本机 Git 配置并保留现有超时限制。

## 验证与剩余范围

`workbench_branches` 使用临时本地仓库及本地 bare 远程验证检出/跟踪、同名拒绝、收藏持久化和失败回退、重命名记录迁移、复合更新及失败现场、变基对象恢复、精确推送租约、歧义上游、过期计划与 post-checkout hook 改变 HEAD。`scripts/check-git-branches.cjs` 对真实 WASM 界面使用模拟 IPC，验证分组/搜索/收藏、远程专属动作、表单失败保留、创建并切换、推送参数、快捷键、确认取消、焦点与窗口边界。

模拟 IPC 不证明原生桌面集成，临时仓库测试不证明网络认证与三系统安装。分支间比较和工作区比较的菜单桥接、worktree 操作、完整冲突处理和交互式变基仍未完成，完整范围继续以 [原始验收清单](workbench-acceptance.md) 为准。
